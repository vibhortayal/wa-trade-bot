1 · Link WhatsApp

One-time step. After the code appears, on your phone go to WhatsApp → Settings → Linked devices → Link a device → Link with phone number instead, and type the code. This page will show “linked” once pairing completes.

2 · API keys

Keys are written to a .env file on this machine (readable only by the bot). They are never displayed again and never sent anywhere except Google's and Supabase's APIs.

3 · Connect TradingView

One-time step. Used only to score trade outcomes against daily price history (5-trading-day window). Read-only market data — it cannot place trades.

4 · Run

Pulls new WhatsApp messages, parses them with Gemini, scores outcomes with TradingView data, and pushes anonymized trades to Supabase. Also runs automatically every hour (06:00–22:00).
